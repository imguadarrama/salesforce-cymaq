## Purpose of the app
The general purpose of the app is to show an interface for the user where he can have all the information for it's report on the MAQCARE plan of CYMAQ.

In this module the user will:

- Track his report made via phone call with the details he needs to know from the report:
    - Report number (generated not random but increasingly from the userid and datetime to create a unique identifier linked for this report)
    - How many hours left for the technical assistance for arrival if required.


Its a simple app for an interview purpose.
